# 서울시 공공도서관 보행 접근성 분석

서울시 250m 격자 생활인구와 OpenStreetMap 보행망을 이용해 공공도서관 접근성을 시각화한 정적 대시보드입니다.

## 로컬에서 보기

이 폴더에서 다음 명령을 실행한 뒤 브라우저로 `http://localhost:8765`에 접속합니다.

```powershell
python -m http.server 8765
```

## 구성

- `index.html`: 연구 질문, 접근성 지도, 행정동 순위, 지표 산점도, 방법과 해석
- `app.js`, `styles.css`: 지도·차트 상호작용과 화면 스타일
- `data/`: 행정동 지표·경계, 도서관 위치, KPI 요약, 행정동 CSV
- `제출요약.md`: 과제 제출용 분석 요약

연구 질문은 “서울시 생활인구의 공공도서관 보행 접근성은 격자와 행정동별로 어떻게 다른가?”입니다. 배포 권한은 Cloudflare Sites 워크스페이스 정책에 따라 별도로 확인해야 합니다.
